# Translations

- `messages/en.json` and `messages/fa.json` always have the SAME keys (the `Messages` type comes
  from `en.json`; a key missing in `fa` breaks the Persian UI at runtime).
- Namespaces by area (`Users`, `DataTable`, `Common`…); keys camelCase; ICU for plurals and
  variables: `"{total, plural, =0 {No users} one {# user} other {# users}}"`.
- Persian copy: natural Persian (not transliteration), use the zero-width non-joiner where needed
  (`می‌شود`), Persian digits are produced by the formatter — don't hard-code them.
- New locale: `routing.ts` (`AppLocale` + `LOCALES_BY_DIRECTION`) + `locales.ts` (label, `dir`,
  `htmlLang`) + `messages/<locale>.json` + the service worker `LOCALES` list.
- `APP_DIRECTION` in `routing.ts` (`"rtl"` | `"ltr"` | `"both"`) decides which languages ship;
  one language → no switcher.
